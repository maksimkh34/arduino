Перед началом

Прежде чем погрузиться в первую главу, убедись, что у тебя есть все необходимое для комфортной работы. Этот учебник — практический, и без реальной сборки схем ты не получишь полного понимания.

Что тебе понадобится​

1. Аппаратная часть​

Обязательный минимум (для разделов 1-2)​

  • Arduino Mega 2560 R3 — основная плата. Именно Mega, а не Uno — у нее больше памяти и пинов, что понадобится в продвинутых главах.
  • USB-кабель Type A - Type B — для подключения Arduino к компьютеру.
  • Breadboard (макетная плата) — минимум 830 точек. Лучше взять 2 штуки среднего размера.
  • Провода папа-папа — набор 40-65 шт разных цветов и длин.
  • Светодиоды (по 5-10 шт каждого цвета):
    • Красные
    • Зеленые
    • Синие
    • Желтые
  • Резисторы (по 10-20 шт каждого номинала):
    • 220 Ом (для LED)
    • 330 Ом (для LED)
    • 1 кОм
    • 10 кОм (для pull-up/pull-down)
    • 100 Ом
  • Кнопки (tactile push button) — 5-10 шт
  • RGB LED (общий катод) — 2-3 шт

Дополнительные компоненты (для разделов 3-9)​

  • Потенциометры 10 кОм — 3 шт
  • Фоторезистор — 2 шт
  • Пьезодинамик (buzzer) — 1-2 шт
  • Семисегментный индикатор (1 разряд) — 1 шт
  • LCD дисплей 16×2 с I2C-модулем — 1 шт
  • LED-матрица 8×8 с драйвером MAX7219 — 1 шт
  • Сервопривод 9g (SG90 или аналог) — 2 шт
  • Ультразвуковой датчик HC-SR04 — 1 шт
  • Датчик температуры и влажности DHT22 — 1 шт
  • Джойстик (2-осевой с кнопкой) — 1 шт
  • Реле 5V — 1-2 шт

Продвинутые модули (для разделов 10-18)​

  • OLED-дисплей 128×64 I2C — 1 шт
  • RFID-модуль RC522 — 1 шт
  • RTC DS3231 (часы реального времени) — 1 шт
  • Матричная клавиатура 4×4 — 1 шт
  • ИК-приемник и пульт — 1 комплект
  • Драйвер моторов L298N — 1 шт
  • DC-моторы 5-6V — 2 шт
  • Шаговый мотор 28BYJ-48 с драйвером ULN2003 — 1 комплект
  • Bluetooth модуль HC-05/HC-06 — 1 шт (опционально)

Где купить: Поищи готовые наборы "Arduino Mega Starter Kit" — они содержат большинство компонентов для первых 5-7 разделов. Остальное можно докупать по мере продвижения.

Стоимость: Минимальный набор для разделов 1-2: ~30−50.Полныйнабордлявсехразделов: 30-50. Полный набор для всех разделов: ~30−50.Полныйнабордлявсехразделов: 100-150.

Полезные инструменты​

  • Мультиметр — для измерения напряжения, тока, сопротивления. Не обязателен, но очень полезен для диагностики.
  • Пинцет — для работы с мелкими компонентами.
  • Кусачки — для обрезки проводов (если будешь паять).
  • Паяльник (опционально) — учебник не требует пайки, но для финальных проектов может понадобиться.

2. Программное обеспечение​

Arduino IDE​

Версия: 2.x (рекомендуется) или 1.8.x (стабильная).

Установка:

  1. Скачай с arduino.cc/en/software
  2. Установи драйверы для Arduino Mega (обычно устанавливаются автоматически)
  3. Запусти IDE
  4. Выбери плату: Tools → Board → Arduino Mega or Mega 2560
  5. Выбери процессор: Tools → Processor → ATmega2560 (Mega 2560)
  6. Выбери порт: Tools → Port → COMX (Windows) или /dev/ttyUSBX (Linux)

Проверка: Загрузи стандартный пример Blink (File → Examples → 01.Basics → Blink) на Arduino. Если встроенный LED (на пине D13) начал мигать — всё работает.

Дополнительное ПО (опционально)​

  • Fritzing — для рисования схем (если хочешь визуализировать свои проекты).
  • Visual Studio Code + PlatformIO — альтернатива Arduino IDE для продвинутых пользователей.
  • Serial Monitor — встроен в Arduino IDE, для отладки через Serial.

3. Знания и навыки​

Что ты уже должен знать​

  • Программирование:
    • Переменные, функции, циклы, условия, массивы
    • Базовый C-подобный синтаксис (C, C++, Java, C#)
    • Указатели и ссылки (базовое понимание)
  • Алгоритмы:
    • Базовые структуры данных (массивы, списки)
    • Понятие о сложности O(n)
  • Математика:
    • Базовая алгебра (уравнения, неравенства)
    • Тригонометрия (синус, косинус — для продвинутых глав)
    • Логарифмы (упоминаются в главах о звуке и сигналах)
  • Физика:
    • Школьная программа: сила, энергия, электричество (базовые понятия)
    • Закон Ома будет объяснен подробно в главе 1.3

Чего НЕ требуется​

  • Опыт в электронике или схемотехнике
  • Знание языка ассемблера
  • Опыт работы с микроконтроллерами
  • Умение паять

Как работать с учебником​

1. Читай последовательно​

Учебник построен как лестница. Каждая глава опирается на предыдущие. Не перескакивай через главы — пропустишь важные понятия.

2. Собирай все проекты​

Чтение кода без сборки схемы даст только поверхностное понимание. Обязательно собирай схемы и загружай код.

Проверяй себя:

  • Схема собрана по таблице соединений?
  • Полярность светодиодов правильная?
  • Резисторы нужных номиналов?
  • Пины подключены к правильным контактам Arduino?

3. Экспериментируй​

В конце каждой главы есть раздел «Эксперименты». Это не опциональные задания — они помогают почувствовать принципы на практике.

Меняй параметры:

  • Другие номиналы резисторов
  • Другие задержки в коде
  • Другие алгоритмы

Смотри, что изменится. Формулируй гипотезы и проверяй их.

4. Проходи самопроверку​

Раздел «Проверь себя» в каждой главе содержит вопросы на понимание. Отвечай на них письменно (или хотя бы мысленно).

Если не можешь ответить — перечитай соответствующий блок теории.

5. Веди инженерный дневник (опционально, но полезно)​

Заведи блокнот или Markdown-файл, где будешь записывать:

  • Схемы проектов (текстово или в Fritzing)
  • Идеи для развития проектов
  • Ошибки, которые ты совершил, и как их исправил
  • Новые понятия и термины

Это поможет структурировать знания и вернуться к проектам позже.

Типичные проблемы перед стартом​

1. Arduino не определяется в системе​

Windows:

  • Установи драйверы CH340 (если у тебя китайский клон Arduino)
  • Проверь, что USB-кабель передает данные, а не только питание

Linux:

  • Добавь себя в группу dialout: sudo usermod -a -G dialout $USER
  • Перелогинься

macOS:

  • Обычно работает из коробки. Если нет — установи драйверы CH340.

2. Ошибка загрузки скетча​

  • Проверь выбор платы: Tools → Board → Arduino Mega
  • Проверь выбор процессора: Tools → Processor → ATmega2560
  • Проверь выбор порта: Tools → Port
  • Закрой все программы, которые могут использовать Serial-порт (PuTTY, screen, minicom)

3. Код загрузился, но ничего не происходит​

  • Проверь схему по таблице соединений
  • Проверь полярность светодиодов (длинная ножка — анод, к плюсу)
  • Проверь, что резисторы нужных номиналов
  • Используй Serial.println() для отладки (откроешь Serial Monitor: Tools → Serial Monitor)

4. Компонент сгорел / дымится​

НЕМЕДЛЕННО отключи Arduino от питания!

Что могло пойти не так:

  • Светодиод подключен без резистора → ток превысил допустимый
  • Перепутана полярность питания
  • Короткое замыкание (VCC напрямую соединен с GND)

Проверь схему заново. Замени сгоревший компонент.

Безопасность​

Общие правила​

  1. Никогда не подключай источник питания напрямую к GND — это короткое замыкание.
  2. Светодиоды всегда через резистор (минимум 220 Ом для 5V).
  3. Не подключай моторы напрямую к пинам Arduino — используй драйверы (L298N, ULN2003).
  4. Максимальный ток пина Arduino — 40 мА (рекомендуется не более 20 мА).
  5. Не работай с сетевым напряжением 220V без соответствующей подготовки и изоляции.
  6. Будь осторожен с Li-Ion/Li-Po аккумуляторами — они могут загореться при неправильном использовании.

Защита Arduino​

  • Используй внешнее питание для мощных нагрузок (моторы, много светодиодов).
  • Всегда соединяй GND Arduino с GND внешнего источника питания.
  • Не подавай более 5V на цифровые пины (они не толерантны к 12V/24V).
