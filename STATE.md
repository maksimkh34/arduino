## Контекст предыдущих глав

### Глава 1.1. Первый контакт: знакомство с Arduino Mega 2560 R3

**Краткая выжимка:**
Читатель установил Arduino IDE, подключил Arduino Mega 2560 R3 через USB, загрузил первый sketch Blink (мигание встроенного LED на D13). Разобрался со структурой программы Arduino (`setup()` и `loop()`), понял базовые функции `pinMode()`, `digitalWrite()`, `delay()`. Познакомился с понятиями микроконтроллера, Flash, SRAM, EEPROM, bootloader. Изучил временные характеристики цифрового сигнала: период, частота, скважность.

**Сформированные навыки:**
- Подключить Arduino к компьютеру.
- Выбрать плату и порт в Arduino IDE.
- Загрузить sketch.
- Понимать структуру `setup()` и `loop()`.
- Использовать `pinMode()`, `digitalWrite()`, `delay()`.

**Введенные понятия:**
- Микроконтроллер (MCU).
- Arduino Mega 2560 R3, ATmega2560.
- Bootloader, sketch.
- Flash, SRAM, EEPROM.
- `setup()`, `loop()`.
- `pinMode()`, `digitalWrite()`, `delay()`.
- `OUTPUT`, `INPUT`, `INPUT_PULLUP`.
- `HIGH`, `LOW`.
- Период, частота, скважность (duty cycle).
- Блокирующая задержка.

**Проекты:**
1. Blink — мигание встроенного LED на D13 с периодом 2 секунды.
2. Анализ Blink — временная диаграмма, понимание регистров PORTB, ограничения delay().
3. Изменение частоты мигания — быстрое мигание (100 мс), очень быстрое (10 мс), асимметричное мигание (2 сек / 0.5 сек).

**Использованные компоненты:**
- Arduino Mega 2560 R3.
- USB-кабель (Type A - Type B).
- Встроенный LED на пине D13.

**Что не повторять подробно дальше:**
- Установку Arduino IDE (можно кратко напомнить, если нужно).
- Выбор платы и порта (можно упомянуть кратко).
- Структуру `setup()` и `loop()` (можно напоминать кратко, но не объяснять заново с нуля).
- Базовое объяснение `pinMode()`, `digitalWrite()`, `delay()` (можно использовать без подробных объяснений).
- Подробное объяснение разницы между микроконтроллером и ПК (можно кратко упоминать для связи).

**Связь с будущими главами:**
- Глава 1.2 использовала `pinMode()` и `digitalWrite()` для управления внешним LED на breadboard.
- Понятие блокирующей задержки `delay()` будет развито в Главе 3.1 (неблокирующие задержки с `millis()`).
- Понятия периода, частоты, скважности понадобятся в Главе 2.1 (ШИМ).
- Цифровые выходы используются во всех главах Раздела 1.

### Глава 1.2. Breadboard и первая внешняя схема

**Краткая выжимка:**
Читатель изучил устройство breadboard: внутренние соединения, контактные группы `a-e` и `f-j`, центральный разрыв, шины питания, координатную систему (`a-j`, `1-63`). Подключил первый внешний светодиод к Arduino через breadboard, разобрался с полярностью LED (анод, катод), понял роль резистора для ограничения тока. Собрал три проекта: один LED на D9, два LED на разных пинах, безопасный анализ схемы без резистора.

**Сформированные навыки:**
- Понимать устройство breadboard: контактные группы, центральный разрыв, шины питания.
- Использовать координатную систему макетной платы.
- Читать таблицу соединений и собирать схему по ней.
- Различать анод и катод светодиода визуально.
- Использовать резистор последовательно со светодиодом.
- Управлять внешними компонентами через цифровые пины.
- Диагностировать типичные ошибки сборки.

**Введенные понятия:**
- Breadboard (макетная плата).
- Контактная группа.
- Центральный разрыв (central gap).
- Шина питания (power rail).
- Джампер (jumper wire).
- Полярность.
- Анод (anode), катод (cathode).
- Резистор как ограничитель тока (вводно, без точного расчета).
- Координаты макетной платы (`a-j`, `1-63`).

**Проекты:**
1. Один внешний LED на пине D9, мигание с периодом 1 секунда.
2. Два LED на разных пинах (D9 и D8) с разными частотами мигания (последовательное управление).
3. Безопасный эксперимент: анализ, что произойдет без резистора (теоретический, без физической сборки).

**Использованные компоненты:**
- Arduino Mega 2560 R3.
- Breadboard (макетная плата).
- Светодиоды (2 шт, разные цвета).
- Резисторы 220 Ом (2 шт).
- Провода папа-папа (джамперы).

**Что не повторять подробно дальше:**
- Устройство breadboard (можно кратко напомнить при необходимости).
- Координатную систему макетки (можно использовать без подробных объяснений).
- Визуальное различение анода и катода (можно напоминать кратко).
- Базовое объяснение роли резистора (можно углублять, но не повторять введение с нуля).

**Связь с будущими главами:**
- Глава 1.3 углубит теорию: закон Ома, точный расчет резистора для LED разных цветов, физический смысл напряжения и тока.
- Все будущие проекты будут собираться на breadboard — это фундамент.
- Понятие полярности пригодится для электролитических конденсаторов, диодов, транзисторов.
