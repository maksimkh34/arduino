### Глава 1.1. Первый контакт: знакомство с Arduino Mega 2560 R3

**Краткая выжимка:**
Читатель установил Arduino IDE, подключил Arduino Mega 2560 R3 через USB, загрузил первый sketch Blink (мигание встроенного LED на D13). Разобрался со структурой программы Arduino (`setup()` и `loop()`), понял базовые функции `pinMode()`, `digitalWrite()`, `delay()`. Познакомился с понятиями микроконтроллера, Flash, SRAM, EEPROM, bootloader. Изучил временные характеристики цифрового сигнала: период, частота, скважность.

**Сформированные навыки:**
- Подключить Arduino к компьютеру.
- Выбрать плату и порт в Arduino IDE.
- Загрузить sketch.
- Понимать структуру `setup()` и `loop()`.
- Использовать `pinMode()`, `digitalWrite()`, `delay()`.

**Введенные понятия:**
- Микроконтроллер (MCU).
- Arduino Mega 2560 R3, ATmega2560.
- Bootloader, sketch.
- Flash, SRAM, EEPROM.
- `setup()`, `loop()`.
- `pinMode()`, `digitalWrite()`, `delay()`.
- `OUTPUT`, `INPUT`, `INPUT_PULLUP`.
- `HIGH`, `LOW`.
- Период, частота, скважность (duty cycle).
- Блокирующая задержка.

**Проекты:**
1. Blink — мигание встроенного LED на D13 с периодом 2 секунды.
2. Анализ Blink — временная диаграмма, понимание регистров PORTB, ограничения delay().
3. Изменение частоты мигания — быстрое мигание (100 мс), очень быстрое (10 мс), асимметричное мигание (2 сек / 0.5 сек).

**Использованные компоненты:**
- Arduino Mega 2560 R3.
- USB-кабель (Type A - Type B).
- Встроенный LED на пине D13.

**Что не повторять подробно дальше:**
- Установку Arduino IDE (можно кратко напомнить, если нужно).
- Выбор платы и порта (можно упомянуть кратко).
- Структуру `setup()` и `loop()` (можно напоминать кратко, но не объяснять заново с нуля).
- Базовое объяснение `pinMode()`, `digitalWrite()`, `delay()` (можно использовать без подробных объяснений).
- Подробное объяснение разницы между микроконтроллером и ПК (можно кратко упоминать для связи).

**Связь с будущими главами:**

- Использовать резистор последовательно со светодиодом.

- Диагностировать типичные ошибки сборки.

**Введенные понятия:**
- Breadboard (макетная плата).
- Контактная группа.

- Джампер (jumper wire).
- Полярность.

3. Безопасный эксперимент: анализ, что произойдет без резистора (теоретический, без физической сборки).

**Использованные компоненты:**

- Светодиоды (2 шт, разные цвета).

### Глава 1.3. Электричество для программистов: напряжение, ток и закон Ома

**Краткая выжимка:**
Читатель изучил фундаментальные понятия электричества: напряжение как разность потенциалов, ток как поток заряда, сопротивление как препятствие току. Освоил закон Ома (`U = I × R`) и его применение для расчета компонентов. Понял, почему LED нужен токоограничивающий резистор: прямое падение напряжения LED (`Vf`) зависит от цвета (красный ~2.0 В, зеленый ~2.2 В, синий ~3.2 В). Научился рассчитывать резистор по формуле `R = (Vsource - Vf) / Iled`, выбирать стандартный номинал из ряда E12. Собрал четыре проекта: расчет резистора для красного LED, сравнение трех резисторов на одном LED, три LED разных цветов с одинаковыми резисторами (увидел разницу в яркости), расчет и проверка резистора для синего LED. Провел эксперименты с мультиметром (измерение напряжения на пине, падение напряжения на LED), экстремальными номиналами резисторов. Понял ограничения тока пина Arduino (max 40 мА, рекомендуется 20 мА) и мощность резистора.

**Сформированные навыки:**
- Понимать физический смысл напряжения, тока и сопротивления.
- Применять закон Ома для расчета компонентов схемы.
- Рассчитывать токоограничивающий резистор для LED по формуле `R = (Vsource - Vf) / Iled`.
- Находить `Vf` LED в datasheet или использовать типичные значения.
- Выбирать ближайший стандартный номинал резистора из ряда E12.
- Измерять напряжение и ток мультиметром.
- Объяснять, почему LED разных цветов требуют разных резисторов.
- Учитывать ограничения тока пина Arduino и мощность резистора.
- Диагностировать проблемы схемы через измерения и расчет.

**Введенные понятия:**
- Напряжение (voltage, U, V).
- Ток (current, I).
- Сопротивление (resistance, R).
- Закон Ома: `U = I × R`.
- Прямое падение напряжения LED (forward voltage, Vf).
- Токоограничивающий резистор (current-limiting resistor).
- Стандартные ряды резисторов (E12).
- Допуск резистора (±5%, ±10%).
- Мощность резистора: `P = I² × R`.
- Ограничения тока пина Arduino (40 мА max, 20 мА recommended).

**Проекты:**
1. Расчет резистора для красного LED (`Vf = 2.0 В`, ток 20 мА) — рассчитан резистор `150 Ом`, использован `220 Ом`, реальный ток ~13.6 мА.
2. Сравнение трех резисторов (`220 Ом`, `330 Ом`, `1 кОм`) на одном красном LED — визуальное понимание связи сопротивления, тока и яркости.
3. Три LED разных цветов (красный, зеленый, синий) с одинаковыми резисторами `220 Ом` — увидели разницу в яркости из-за разного `Vf`.
4. Расчет резистора для синего LED (`Vf = 3.2 В`, рассчитан `90 Ом`, использован `100 Ом`) — сравнение с резистором `220 Ом`, синий LED стал ярче.

**Использованные компоненты:**
- Arduino Mega 2560 R3.
- Breadboard.
- Светодиоды: красный, зеленый, синий (стандартные 5 мм).
- Резисторы: `220 Ом`, `330 Ом`, `1 кОм`, `100 Ом` (опционально).
- Провода папа-папа.
- Мультиметр (опционально, для экспериментов).

**Что не повторять подробно дальше:**
- Физический смысл напряжения, тока, сопротивления (можно кратко напомнить при необходимости).
- Закон Ома и его вывод (можно использовать как данность).
- Расчет токоограничивающего резистора для LED (можно кратко напомнить формулу).
- Стандартные ряды резисторов (можно упоминать без подробного объяснения).
- Базовое использование мультиметра для измерения напряжения (если было в экспериментах).

**Связь с будущими главами:**
- Глава 1.4 углубит понимание логических уровней: `HIGH` и `LOW` как физические напряжения ~5 В и ~0 В, пороги распознавания TTL.
- Глава 2.1 (ШИМ): расчет среднего тока и мощности при ШИМ-управлении яркостью LED опирается на закон Ома.
